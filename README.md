# MuscleTrack — Version 0.3

A Flutter Android workout logger for recording training sessions and reviewing strength progress.

## Included in v0.3
- Local profile with name or nickname
- Workout logging with exercises, sets, reps and load
- Editable workout history
- Training calendar
- Training-volume calculation
- Estimated 1RM using the Epley equation for strength trends
- Session duration and notes
- Local SQLite storage
- Full local-data deletion control

## Data model
Version 0.3 is focused on workout records. It does not provide meal logging, dietary tracking, medication logging or disease-management features.

## Dependencies
- Flutter / Dart 3.x
- `sqflite`
- `path`

## Android identity
- Application ID: `au.com.muscletrack.t2d` (retained for continuity with the existing Google Play app)
